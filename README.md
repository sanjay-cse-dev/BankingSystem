# Banking System

A Core Java banking system built for learning
OOP, layered architecture, validation and exception handling.

## Current Features

- Account registration
- Login
- Deposit
- Withdraw
- Balance check
- Console-based UI

## Tech Stack

- Java
- Maven
- HashMap

## Architecture

ConsoleUI
→ BankingServices
→ BankingServiceImpl
→ AccountRepository
→ Account
